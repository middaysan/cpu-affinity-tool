## [1.7.0] - 2026-10-22

### Summary
Save process rules, see where CPU time goes, and manage the same setup through a local agent. This release adds CPU/process history, selected Windows controls and optional MCP access, alongside a more compact interface and Windows rendering fixes.

### Added
- **CPU history:** record activity with graphs closed or the app in the tray. Choose a bounded 30-second, 5-minute or 30-minute RAM history; inspect logical CPUs, sampled parking state and process contributors in shared **Graphs / Processes** windows with sortable tables.
- **History exports:** right-click a graph to save its visible chart as PNG or export all retained CPU/process history as UTF-8 CSV. Agents can download the same history through MCP.
- **System Tweaks:** inspect and change selected Windows settings with explicit Apply/Undo controls, owned-value recovery and confirmation for display changes. Includes AC power mode, Game Mode, background clips, windowed-game settings, refresh rate, per-app GPU preference, accessibility shortcuts and mouse acceleration. Read-only guidance and PC checks are available alongside them.
- **Local AI-agent control:** one Windows EXE includes a localhost Streamable HTTP MCP server, disabled by default. Copy connection details or a self-contained setup prompt. Agents can manage saved groups/rules, monitoring and supported Windows settings; launch programs, inspect exact process instances, read bounded output/logs/crash reports and download CPU history. The window retains the latest 100 commands.
- Running-process name suggestions when editing tracked executable names.

### Changed
- Windows uses WGPU/DirectX 12 with memory-oriented allocation hints, shared text rasterization, bounded font preparation and cached chart/table work. Linux retains its separate Glow desktop beta path.
- Compact header controls for MCP, Process monitor and CPU load; consistent dimmed modals, process tables, theme selection and CPU tiles. **Group CPU load** shows tracked work on the group's CPUs, while the header shows overall system load. Process monitoring and CPU recording remain independent.
- More room for application names and full-width paths; a fixed group toolbar, clearer rule settings and refreshed documentation with actual application screenshots.
- Source builds require Rust 1.95 or newer. Local renderer/window patches retain upstream provenance and regression coverage.

### Fixed
- Window growth and crashes when dragging between monitors with different scaling; correct group targeting for ordinary Explorer drops into the elevated app.
- Hidden startup, tray restoration, orderly graphics teardown and reachable startup errors.
- Delayed/final CPU work, reused PID attribution and graph export menus after theme changes. Missing or partial measurements remain explicit.
- MCP worker bounds across listener restarts, exact-exit scheduling metadata reclamation, saved-launch priority preflight and bounded run labels/output responses.
- Ended-session recovery when Windows retains old logon records.

### Upgrading and limits
- Back up the active `state.json` before upgrading; **Logs → Data folder** opens its directory. An explicit save upgrades older formats to schema v11. Loading pre-v6 data also creates a `state.json.pre-v6*` backup; v6 and later do not get that particular backup. Downgrading after a current-format save is unsupported. Existing monitoring preferences are preserved.
- New rules default child-process management to off. Existing pre-v10 rules retain the prior enabled behavior when that field was absent. Start minimized does not register Windows sign-in startup.
- CPU history stays in RAM until exported; turning CPU recording off releases it. Exports contain the retained period, not an unlimited archive. System Tweaks changes can persist after exit; Undo preserves later changes made elsewhere.
- One permanent MCP key grants full access to supported tools. Share it only with a trusted agent. Ordinary-user launch is the default; administrator launch is explicit. Disabling MCP does not terminate resumed programs or stop independent CPU recording.
- Stable artifacts are unsigned portable **Windows x64** files and require administrator approval. CPU recording, System Tweaks and production MCP are Windows-only. Linux remains a separate desktop beta; no installer or package-manager distribution is included.
- Protected processes may refuse scheduling changes. No performance gain is guaranteed. Graphics-device loss during driver replacement requires restarting the app. Host-specific checks do not certify every Windows/GPU combination; rare GPU timing tails remain unresolved and were accepted as nonblocking.
